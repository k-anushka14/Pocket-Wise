# PocketWise 💰

A smart student-focused personal budget tracker designed to help students
manage pocket money, track expenses, set savings goals, and understand
their spending habits.

> 🚧 **Status: Under Active Development**
>
> PocketWise is currently being developed and new features are being added.

## Tech Stack

- React
- FastAPI
- PostgreSQL / Supabase
- Python
- JavaScript

## Current Features

- User authentication
- Income tracking
- Expense tracking
- Budget management
- Savings goals
- Expense categories
- ...

## Planned Features

- Spending insights
- Financial health score
- Smart recommendations
- ...
